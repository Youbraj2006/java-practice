# Java Basics Project

This project contains basic Java programs to understand core concepts like:

- Variables (instance and local)
- Data Types
- Methods
- Classes and Objects

## Files Included
- B_Variable.java → Example of instance and local variables
- C_DataTypes.java → Example of basic data types

## How to Run
1. Compile the program:
   javac FileName.java

2. Run the program:
   java FileName
